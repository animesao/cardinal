# Active work

Work-in-progress records live here, one file per task or branch.

Start from [`../templates/task.md`](../templates/task.md), then fill in
[`../templates/handoff.md`](../templates/handoff.md) before stopping.

Delete the record when the work is complete, or move it to `docs/plans/` when it
is useful as historical intent. Do not leave completed tasks here.
